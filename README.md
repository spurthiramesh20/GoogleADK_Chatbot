## GoogleADK Chatbot

Python chatbot project with a small web UI and evaluation utilities.

### Project layout

- `src/`: application code and web UI assets
- `evaluator/`: evaluation scripts
- `requirements.txt`: Python dependencies

### Quick start

```bash
python -m venv venv
venv\\Scripts\\activate
pip install -r requirements.txt
```

### Notes

- Put secrets in `.env` (ignored by git).
- Python cache files (`__pycache__`, `*.pyc`) are ignored.
